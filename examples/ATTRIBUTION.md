# Attribution

paragraph break) of a Wikipedia article, otherwise unchanged, licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
by the article's authors (see each link's page history). It's demo data for
the README charts - not part of the MIT-licensed code.
